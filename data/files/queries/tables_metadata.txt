RM2 Database table structure summary
Phase 1 – Core maintenance

Products

Product is the generic product information table. In a multisite, the product table data is the same at all branches. The pri mary ket of this
table is used as a foreign key in many other tables. Each product record can be associated to multiple barcodes an d multiple
supplierproducts.

barcode table contains details specific to each barcode within a product.

Prices

Prices are the retail price values associated to each barcode. They have an effective date for when they become live and the most
recent effective date that has the released flag active is the current price on till.

Column  Description  Linked PK  Linked Table
prc_pk  Primary Key
prc_barfk  Foreign key for associated barcode.  bar_pk  barcodes
prc_banfk  Foreign key for relevant price band (multisite functionality).  ban_pk  pricebands
prc_price  Retail selling price value
prc_effective  Effective Date for when the price change goes live.
prc_labelbatch  Foreign key for most recent associated label batch.  lba_pk  labelbatch
prc_released  Status flag. Price becomes active on till after it is released.
prc_timestamp  Timestamp for when price record was last updated.
prc_cashier  Cashier Name that created / updated.
prc_preafk  Reason for change  prea_pk  pricechangereasons
prc_accepted  Status flag for price change approval. Mostly redundant
multisite option.

CostPrices

Cost prices are the supplier cost charged to the retailer per case and are associated to a supplierproduct. There can be mult iple
historical costs for each SupplierProduct record. Cost prices have an effective date and the most recent effective date is co nsidered the
current cost price.

Column  Description  Linked PK  Linked Table
cst_pk  Primary Key
cst_sprfk  Foreign key for associated supplierproduct  spr_pk  supplierproducts
cst_price  Cost price value
cst_effective  Effective date
cst_timestamp  Timestamp for when record was last updated.
cst_cashier  Cashier name that added / updated.



VcostPrices

VcostPrices is a view and not stored as a table in the database. It returns to current base case cost price for each supplier product
queried.

Column  Description  Linked PK  Linked Table

Vatrates

Vatrates are the VAT % levels of sales tax applied to products. This is used in margin and profit calculations.

Column  Description  Linked PK  Linked Table
vat_pk  Primary Key
vat_code  Vat Code
vat_description  Description
vat_rate  Rate as Percentage
VAT_TIMESTAMP  timestamp for when record was last updated
vat_newrate  New Rate
vat_changedate  Date to be changed
vat_oldrate  Old Rate
vat_created  Date Created
